## New

- Motty updates itself: it downloads the release from the mirror, checks its SHA-256 and signature, and restarts into the new version. Installs it does not own (a .deb, Program Files, a portable copy) still open the download page.
- Local Claude Code, Codex and OpenCode CLI providers, each with its own login terminal.
- A per-host outbound proxy: inherit, direct, SOCKS5 or HTTP CONNECT.
- Copy the MCP client configuration for 13 clients from Settings.
- Import Electerm bookmarks with their nested groups.
- Save a host password when creating or copying a host; hosts with the same endpoint can share it.
- Duplicate a tab and close a pane from the interface.

## Fixed

- Ctrl+C reaches a terminal without a selection again.
- AI rename dialogs take their buttons again, and the wheel no longer scrolls the panel behind them.
- The host form keeps its fields on one grid in a narrow window.
