## 新功能

- 终端旁边可以打开资源监控，查看 CPU、内存、磁盘、网络和负载。
- 监控支持 1 / 2 / 5 秒刷新，可以暂停和恢复，采样失败会说明原因。
- 终端新增滚动条，有回滚内容时出现在右侧。
- 设置 > 终端可以开启选中即复制和右键粘贴。
- 终端字体后面可以再加最多三个回退字体。
- 代码字体配一个中文字体，就能同时正常显示两种字形。
- 文件面板支持后退、前进和「最近目录」。
- 文件面板刷新时不会打断正在浏览的目录，导航可以取消。
- 可以直接打开 Xshell 的 `.xsh` 文件里的 SSH / Telnet 会话。
- 设置 > 通用可以选择关闭窗口时留在托盘还是直接退出。
- 输入里出现容易误读的形近字符时，会在发送前提示。
- shell 不是 UTF-8 时会提示中文退格可能留下残缺字节。
- 可以只修复当前会话的字符处理，不改系统设置和启动文件。
- 助手面板里的用户消息、回答和工具输出都可以选中复制。

## 改进

- 诊断日志会记录窗口隐藏、关闭和正常退出。
- Windows 11 22H2 及以上会保留系统原生崩溃转储。
- 本地文件面板里的 `.app` 会显示系统图标。
- 刷新时未变化的包保留原图标，不再当成普通文件夹。
- 关于页新增「构建于 Viva」和仓库链接。
- 开发版在 Dock 上显示 DEV 徽标，界面外观与正式版一致。

## 修复

- 阿里云 OSS 等返回 400 `NotImplemented` 的服务，S3 同步不再全部失败。
- 服务器要求再次多因素认证时，提示不再误说是密码错误。
- 助手面板里用户消息和工具输出之前无法正常选中复制。
- 开发用的 watch 构建在第一轮失败时，Ctrl-C 能干净退出。
