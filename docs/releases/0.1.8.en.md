## New

- The file panel can browse both panes in sync and store paired folders as location profiles; a new Places sidebar keeps favorites and jumps to home, desktop, downloads, documents, pictures, drives and the rest.
- Dropping files from the system onto a connected server’s terminal uploads them to the folder the shell reports, with a notice when the upload starts and one when it ends.
- Tabs can be locked, so closing one asks first; local tabs remember the folder they were in.
- A Windows portable zip keeps hosts, settings, the vault and AI data in a motty-data folder next to the program; it asks for a master password and the in-app updater sends it to the download page.
- Settings > Terminal > Local shell lists installed WSL distributions, and the file panel follows their folders through \\wsl.localhost.
- The data folder keeps motty.log and a crash report after an abnormal exit; a failed start explains itself in a dialog, and starting again brings the running window forward.
- A snippet can be sent straight from the Snippets page, and you choose the target terminal when several are open.
- The assistant’s approval scope can be switched inside a conversation, with each level saying what runs without asking.
- Remote process and resource views can search the loaded snapshot by PID, user, command or name.

## Improvements

- Assistant requests now mark cache breakpoints on the unchanged prompt prefix, and the usage line shows how many tokens came from the cache.
- A large or partially unreadable folder says how much was loaded, what was skipped and why, instead of passing off a partial listing as complete.
- Both panes filter, hide and sort independently, and the header menu can sort by name, size or modified time.
- The transfer center retries failed items and resolves conflicts in bulk, limited to the failures it captured for that host.
- Terminal-follows-file-navigation now works on Bash 4.2 and 4.3 through a private DEBUG trap.

## Fixes

- Importing a PuTTY .ppk no longer accepts a Private-MAC of the wrong length, and the Argon2 parameters are bounded so a damaged key cannot ask for impossible memory or time.
- Closing a terminal split restores the full output and width instead of leaving rows clipped to the narrower size.
- Text input after a tab closes is routed to the right session, and remote views refuse changes on a stale or changed process snapshot until it is refreshed.
