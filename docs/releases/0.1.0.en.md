## New

- Native SSH terminal with tabs and split panes.
- Hosts, groups and tags, with password or key authentication and jump chains.
- An SFTP browser beside the terminal: upload, download, rename and delete.
- Port forwarding managed in the interface: local, remote and dynamic.
- VNC and RDP desktops in the same window.
- An AI assistant and an MCP server that work on the session in front of you.

## Packaging

- Packages for macOS (arm64, amd64), Windows (amd64, arm64) and Linux (amd64, arm64). The macOS builds are signed, notarized and stapled; the Windows and Linux builds are unsigned.
