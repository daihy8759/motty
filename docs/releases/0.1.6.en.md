## New

- The file panel follows the folder the SSH terminal is in by default. New bash and zsh sessions report their folder for that session only, without touching the server’s startup files. Settings > Files also has a separate “Terminal follows file navigation” switch, off by default, which changes the same terminal’s folder at a verified empty prompt and otherwise says why it did not.
- The host editor picks an existing connection group or creates one from the name you type.
- Settings > Terminal > Local shell chooses an installed shell for new or reconnected local terminals on Windows, picked from what Motty finds on PATH and in the usual install folders.
- WebDAV and S3 backups can use a remote HTTP address after an explicit confirmation. HTTPS stays the default, the form keeps warning that HTTP is not encrypted, and the backup is still encrypted on this computer before upload.

## Improvements

- The main window, file windows and remote tool windows keep a usable minimum size instead of letting controls be cut off.
- The docked assistant panel can be dragged wider: its width is bounded only by the room the content beside it keeps, with the navigation rail counted as part of that room.
- In narrow windows, section toolbars turn into labelled icon buttons when they do not fit, host rows give up their status words but keep the light, and titles wrap or ellipsize instead of running under the buttons.
- Assistant CLI settings probe what the installed CLI can do instead of checking versions: they show the path found or say none was found, and name the missing capability, the failed check command or an isolation setting that did not apply.

## Fixes

- A server that only allows SFTP keeps its connection when the shell is refused, and the file panel keeps working. A connection also stays while a file panel or file window still uses it after the shell ends.
- The file panel breadcrumbs come back when the path input loses focus.
- Remote process lists parse the fields of older procps again.
- Folder reports that arrive while the file panel is opening, busy or editing its path no longer move it; only the latest one is applied.
