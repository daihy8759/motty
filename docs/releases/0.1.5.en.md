## New

- Settings > General customizes the window, terminal and SFTP toolbars: which buttons are shown and in what order, dragged or moved with the keyboard, applied immediately, with enable all, disable all and restore defaults.
- A connection’s color now marks its host card and its tab, and the file window header uses the same color as the terminal.
- A file panel can filter the current folder by name with a match count, show or hide hidden files, and edit its path directly with Command/Ctrl+L.
- Settings > MCP separates the HTTP server, which uses the sessions open in Motty, from the standalone service a client starts (`mcp-serve`, over the hosts you opened to agents); each has its own client list, preview and copy button.
- Both transports can grant full access: commands, reads, writes and deletes run without approval. It is saved only after a risk confirmation, stays flagged while configured, and for the standalone service adds `sftp_write` and `sftp_remove` and takes effect when the client restarts it.
- The assistant keeps its primary connection when you switch tabs; acting on another session needs an @ reference or an explicit request, and cross-connection commands and file changes show their real target for approval.
- The Docker view says when Docker is not installed, sorts by column, and can refresh every 5 seconds to 5 minutes.
- Release notes in the update dialog are rendered Markdown, with clickable links.

## Improved

- The Ask level is spelled out: low-risk actions run, the rest need approval in the AI panel, and critical ones need a typed confirmation.
- Custom Windows install directories update in place now, keeping the original directory; an older build that could only offer a download has to be replaced by hand once.
- On Apple Silicon under Rosetta the update installs the arm64 package.
- The status icon is created after the first window is up.

## Fixed

- Page content stays inside the workspace border while scrolling.
- Transfer progress and results stay in the detached file window’s own footer.
- The assistant drawer no longer sits over dialogs.
