## 新功能

- Motty 可以自己更新了：从镜像下载安装包，校验 SHA-256 和签名后重启进入新版本。不是自己持有的安装（.deb、Program Files、便携版）仍会打开下载页。
- 本地 Claude Code、Codex、OpenCode CLI 提供方，各自带登录终端。
- 每台主机可单独设置出站代理：继承、直连、SOCKS5 或 HTTP CONNECT。
- 在设置里复制 13 种客户端的 MCP 配置。
- 导入 Electerm 书签及其嵌套分组。
- 新建或复制主机时保存密码，同一地址的主机可以共用。
- 界面里复制标签页、关闭分屏。

## 修复

- 终端没有选中内容时也能收到 Ctrl+C。
- AI 重命名对话框的按钮恢复可点，滚轮不再滚动背后的面板。
- 窄窗口下主机表单的字段保持在同一栅格。
