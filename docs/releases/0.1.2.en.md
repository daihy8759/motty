## New

- An About page in Settings shows this copy's version, platform, build commit and runtime, with one button that copies them for a bug report, and links to the community, the repository, the issue tracker and motty.page.
- Hosts now sync both ways with ~/.ssh/config: host, user, port and ProxyJump travel either direction and IdentityFile lands in Keys. The file keeps its comments and unknown directives, a block naming several hosts is left alone, and when both sides changed the file wins.
- Select text inside an AI answer and copy it; a fenced block keeps its own line breaks and indentation.
- Command/Control+Shift+T opens a local terminal.
- Check for Updates… in the status-area menu.

## Improved

- Updates are checked five seconds after a window wakes and then once an hour, on by default.
- An install the system owns (a distribution package, /snap, Flatpak, Program Files) is told to update through its package manager or the new installer, and is still never replaced by the app with elevation.
- Every package carries a minisign update signature that names its version and file, and the app verifies it before replacing anything. Windows can now update in place without a code-signing certificate; macOS still checks the Developer ID team.
- The component gallery is a development-only surface and no longer appears in release builds.

## Fixed

- A UTF-8 control string could leak its continuation bytes into the input line as text. Raw eight-bit C1 DCS/ST/OSC/APC are no longer interpreted as controls; use their seven-bit ESC forms.
- The MCP configuration preview names itself in its header.
