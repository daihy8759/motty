## New

- X11 forwarding no longer needs DISPLAY set by hand: Motty finds the local X server itself.
- When no X server is running, it says what to install and what to check on the server.
- The SFTP file list can show size and modified columns, reordered by dragging.
- Synced browsing offers to create the matching folder when the other side lacks it.
- A local file opens straight from the file panel.
- Processes and Docker on Windows and macOS servers show up in the remote tools.
- Monitor panels dock on either side, with their empty states centered.

## Improvements

- One mouse wheel notch scrolls one row instead of needing many.
- A saved password answers keyboard-interactive password prompts instead of asking every time.
- The terminal latency probe starts at wake and has a ceiling, so the numbers match what the user feels.
- Catalog pages share their empty-state copy and spacing.

## Fixes

- Deleting a host that a jump route, a port forward or a session still uses now says what to deal with first.
- Saved SFTP folders refresh, and damaged column settings recover.
- Actions that cannot run are disabled and explained instead of doing nothing.

## Install

| Platform | Packages |
| --- | --- |
| macOS (arm64, amd64) | `.dmg`, `.zip` |
| Windows (amd64, arm64) | installer, portable zip (data in `motty-data` beside the program) |
| Linux (amd64, arm64) | `.deb`, `.tar.gz` |
