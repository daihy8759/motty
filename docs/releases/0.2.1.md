## 新功能

- X11 转发不用再手动设 DISPLAY，Motty 会自己找本机的 X server。
- 找不到或连不上 X server 时，会说明要安装什么、服务器上要检查什么。
- SFTP 文件列表可以配置显示大小和修改时间列，并拖动调整顺序。
- 同步浏览遇到对侧没有对应目录时，可以直接创建并继续。
- 本地文件面板里可以直接打开文件。
- Windows 和 macOS 服务器上的进程和 Docker 也能在远程工具里查看。
- 监控面板可以停靠在左右两侧，空白状态居中显示。

## 改进

- 鼠标滚轮一格滚一行，不再要滚很多次才动一行。
- 键盘交互提示要求密码时直接使用已保存的密码，不再每次弹框。
- 终端延迟统计从唤醒开始并加上了上限，结果更贴近真实响应。
- 各目录页的空状态统一了文案和留白。

## 修复

- 主机被跳板、端口转发或会话占用时，删除前会说明原因。
- 保存的 SFTP 目录会刷新，列设置损坏后能恢复。
- 不能执行的操作会置灰并说明原因，不再点了没反应。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
