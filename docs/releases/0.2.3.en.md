## New

- The assistant accepts files and images dragged onto it, or picked with the paperclip.
- Word, Excel and PowerPoint documents are read and attached to the question.
- A screenshot on the clipboard can be pasted into the message box and attached.
- Offline command completions: Command+Shift+J (Control+Shift+J on Windows and Linux) lists the commands, subcommands, options and values that fit the current input.
- Completions can be turned off, shown as a list, or as a list plus inline grey suggestions.
- A local terminal on Windows can start a different shell or WSL distribution per tab.
- New shortcuts: clear screen (Command+K on macOS, Control+K elsewhere), next and previous tab (Control+Tab and Control+Shift+Tab).
- Command+1..9 now switches tabs on macOS, from any page.

## Improvements

- The assistant's session selector uses the same chip size as the controls beside it.
- A shortcut can be bound to a named key such as Tab, Page Up, Page Down or an arrow.

## Fixes

- Local terminals start in a UTF-8 locale, so Chinese file names and output are no longer garbled.
- Gateways that only understand pty and shell requests are no longer sent a locale request, so the session is not closed before the shell opens.
- The SFTP list no longer jitters when scrolled past its edges.

| Platform | Packages |

| Windows (amd64, arm64) | installer, portable zip (data in `motty-data` beside the program) |
| Linux (amd64, arm64) | `.deb`, `.tar.gz` |
