## New

- SFTP opens in its own window with the local and remote panes side by side; rows sort, drop onto each other, and a pane can connect straight to a host.
- A global transfer center lists every upload and download with its progress and lifetime, and keeps going after the window that started it closes. The file panel shows the transfer list by default and docks left or right, and its path bar is editable with a choice of style.
- Compress a remote folder into a zip on the server itself, and extract more archive formats with a notice of how it went.
- Preview images and edit text in a native window: the encoding is detected, and the main window stays free.
- Remote tools open in their own native window and run alongside the main window; legacy Docker and ps output is understood, and a container gets its own terminal.
- Each host can choose its own authentication methods and its own SOCKS5 or HTTP CONNECT proxy, credentials included.
- A connection can carry its own color into the terminal header and tool buttons, picked with a round eyedropper in the form; the host form rows got roomier.
- Host tags are a searchable multi-select that can create an entry on the spot.
- Import model providers from magpie and cc-switch, drawn with their official marks.
- Close a split pane from the terminal menu and the keyboard follows the pane you enter; the command palette keeps the highlighted row under the pointer and takes arrow keys in its search field.

## Improved

- Every pull request runs the full Go checks, and the race detector is sharded with cached builds so the gate finishes sooner.
- The debug gallery gained a color swatch.

## Fixed

- The local file panel no longer reports an SFTP EOF when it enters an empty directory.
- A restored tab starts disconnected instead of reconnecting on its own.
- Set Model in the AI panel opens the AI settings page.
- The command palette, overlay close buttons and the new-tab picker take their clicks and keys where they are drawn.
- An RDP server can no longer make the client hold unbounded pixel memory.
- The macOS update helper runs from a full copy of the bundle, so the replacement lands reliably.
