## New

- An AI provider can use the Chat Completions (default) or Responses request format.
- A gateway that only serves `/v1/responses` can be added now.
- A trailing `/responses` or `/chat/completions` in the address is removed.

## Improvements

- The provider dialog shows the path the chosen format actually requests.

## Fixes

- The AI panel's message and history scrollbars can be dragged.

## Install

| Platform | Packages |
| --- | --- |
| macOS (arm64, amd64) | `.dmg`, `.zip` |
| Windows (amd64, arm64) | installer, portable zip (data in `motty-data` beside the program) |
| Linux (amd64, arm64) | `.deb`, `.tar.gz` |
