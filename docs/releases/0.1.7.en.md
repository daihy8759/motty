## New

- Snippets have their own page in the sidebar, below Known Hosts: a table of each command’s name, shortcut and text, with add, edit and delete. Every snippet can have a shortcut of its own, set by pressing the keys in its dialog. It cannot collide with a built-in shortcut or another snippet, Control alone needs Shift or Alt so keys like Ctrl+R keep working in the terminal, and it only sends while the terminal page is showing. Shortcuts stay on this device.
- Connection settings choose the ssh-agent: the system agent, 1Password, Bitwarden, or a custom socket or named pipe, kept per device. Windows connects to the OpenSSH pipe by default, and an agent that cannot be reached is listed as skipped with its address.
- Keychain can save the passphrase of an encrypted key (Save Passphrase), checked against the key first and kept in the vault; saving it empty forgets it.
- Pasting in an SSH terminal while the clipboard holds an image and no text uploads the picture to ~/.cache/motty/paste on the server (SFTP, or SCP when there is no SFTP) and types its path, so programs such as Claude Code can read it. Files are private to the account, uploads older than a week are pruned, and a setting turns it off.
- The terminal follows the window between light and dark, and each look remembers its own color scheme.
- RDP hosts have a switch to connect to the console (admin) session.

## Improved

- Private keys that begin with ENCRYPTED PRIVATE KEY (the default of OpenSSL 3 and ssh-keygen -m PKCS8) now open and ask for the passphrase like any other encrypted key. A key file that exists but cannot be used is listed as skipped with its reason.
- The files panel of a local terminal opens at, and follows, the folder the shell is in (local bash and zsh; Windows shells are not covered).
- Programs that copy on selection (Claude Code, tmux set-clipboard) no longer raise a prompt on every drag: OSC 52 writes are allowed, reads stay denied, and the ask dialog gains Always allow.

## Fixed

- With a files panel open beside a terminal, the part of the terminal as far from its left edge as the panel is wide no longer swallows the mouse wheel.
- Reopening or restoring the remote tools window reads the active tab again, so a container created later no longer looks deleted.
- The chosen terminal color scheme is marked with a check; a dark scheme in a light window used to look unselected.
- Clicking outside the key passphrase prompt no longer skips that key, and a key whose fingerprint is unknown until unlocked can no longer be pinned to a host or block removing the key.
