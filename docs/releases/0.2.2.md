## 新功能

- AI 服务商可以选择 Chat Completions（默认）或 Responses 请求格式。
- 只提供 `/v1/responses` 的网关现在也能接入。
- 地址末尾的 `/responses` 或 `/chat/completions` 会自动去掉。

## 改进

- 服务商对话框会显示所选格式实际请求的路径。

## 修复

- AI 面板的消息列表和历史记录滚动条可以拖动。

## 安装

| 平台 | 包 |
| --- | --- |
| macOS（arm64、amd64） | `.dmg`、`.zip` |
| Windows（amd64、arm64） | 安装程序、便携版 zip（数据在程序旁的 `motty-data`） |
| Linux（amd64、arm64） | `.deb`、`.tar.gz` |
