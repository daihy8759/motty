## New

- Monitoring dashboards group several SSH hosts and show their CPU, memory, disks and network on one screen.
- A dashboard has simple and detailed views, group filters, drag ordering, and its own sampling interval and retention.
- Dashboards start and stop collection, retry failures, and open a host’s terminal.
- A remote bell plays the system alert sound and can be switched off.
- Links open with Cmd/Ctrl held; a plain click selects and copies, and a setting restores the old behavior.
- The alternate screen scrolls with the wheel by default, so pagers and editors get arrow keys.
- Tabs can follow the title a program reports with OSC 0/2.
- On macOS, Command+Left/Right/Delete send Ctrl+A/E/U.
- Host secret fields have show/hide buttons, and the host form asks for a single key’s passphrase.
- Passwords and one-time code secrets follow the host: editing the address keeps them, and deleting the host removes them.

## Improvements

- The vault no longer uses a master password: its key lives in the system secret store, or in a vault.key beside the data when there is none (and in portable copies).
- Data saved with a master password is converted once on first launch; older builds can no longer open the new data.
- The terminal scrollbar appears only under the pointer and lights up briefly after keyboard scrolling.
- Monitor panels page with PageUp/PageDown and collect with less overhead.

## Fixes

- Dragging a selection past the edge scrolls the view and keeps the selection on its text.
- Long selections copy through OSC 52 in chunks instead of failing.
- The send confirmation no longer appears while output is still unparsed.
- zsh history survives across sessions on macOS.
- Option and Command editing keys work in the assistant composer.
