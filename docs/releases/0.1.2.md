## 新功能

- 设置里新增「关于」，显示这一份 Motty 的版本、平台、构建 commit 和运行时，一个按钮把它们复制下来贴进 issue，并提供社区、仓库、issue 和 motty.page 的入口。
- 主机与 ~/.ssh/config 双向同步：host、user、port、ProxyJump 两个方向都同步，IdentityFile 落到 Keys。文件保留注释和未知指令，一条 Host 行带多个主机名的块不动，两边都改时以文件为准。
- AI 回答里的文字可以选中并复制，代码块保留原有的换行和缩进。
- Command/Control+Shift+T 打开本地终端。
- 状态栏菜单里的「检查更新…」。

## 改进

- 窗口唤醒 5 秒后检查一次更新，之后每小时一次，默认开启。
- 系统持有的安装（发行版包、/snap、Flatpak、Program Files）会被告知用包管理器或新安装包更新，应用仍然不会提权替换它。
- 每个包都带 minisign 更新签名，签名里写明版本和文件名，应用在替换任何东西之前先校验。Windows 不再需要代码签名证书也能原地更新；macOS 仍校验 Developer ID 团队。
- 组件画廊只在开发构建里出现，发布构建不再包含它。

## 修复

- UTF-8 控制字符串里的续字节此前会漏进输入行变成文字。原始的八位 C1 DCS/ST/OSC/APC 现在不再被当作控制符解释，请改用七位 ESC 形式。
- MCP 配置预览的头部写明它的名称。
