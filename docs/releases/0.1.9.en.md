## New

- A resource monitor can sit beside the terminal, showing CPU, memory, disks, network and load every 1, 2 or 5 seconds.
- The terminal has a scrollbar, and Settings can turn on copy on select and right-click paste.
- Up to three fallback fonts can follow the terminal font, so a code font and a CJK font render together.
- The file panel has back, forward and recent folders, and navigation can be cancelled.
- Xshell .xsh files open their SSH and Telnet sessions directly.
- Closing the last window can quit or stay in the tray, chosen in Settings.
- Look-alike command characters and a shell that is not UTF-8 are flagged before sending, with a per-session fix.
- User messages, answers and tool output in the assistant panel can be selected and copied.

## Improvements

- Diagnostics log the window being hidden, closed and exiting normally, and Windows keeps native crash dumps.
- Local .app bundles show their system icon in the file panel.
- The About page credits Viva and links to its repository.
- Development builds show DEV on the Dock badge.

## Fixes

- S3 sync no longer fails entirely on services such as Aliyun OSS that answer 400 NotImplemented.
- A repeated multi-factor round no longer blames the password.
- Text in the assistant panel could not be selected or copied; it can be now.
- Ctrl-C now stops a watch build that failed on its first round.
