## New

- A new Session Logs page keeps a local record of each connection's target, start time and how it ended, filterable by time, status, protocol and favorite.
- Session recording can be turned off in Settings, and records can be cleared except favorites or entirely.
- The assistant can answer about several ticked connections at once, up to seven per question.
- A terminal in a split tab can be renamed from its context menu, so the selector and @ mentions tell the panes apart.
- Terminal colors add Windows Terminal's default scheme.
- MCP client configuration adds Pi Coding Agent.

## Improvements

- Choosing a sidebar or settings row plays a short motion of its icon that matches the glyph.

## Fixes

- Tailscale SSH connections start shell integration, so the file panel follows the working directory again.
- A tool call a provider writes as text is executed instead of being shown as the answer.
- An answer that reaches the model's output limit says it was cut off at the end.
- A conversation that receives no data for long ends with an error instead of waiting.
- Host cards in the workbench show the address, with the checkbox centered.
- The assistant's target list is as wide as its longest row, so long names are not cut off.
