## New

- `motty mcp-serve` is an MCP server over stdio: an agent starts it itself, with no port and no token, and it ends with that agent. It reaches only the hosts you opened to agents under a host’s Advanced settings.
- Agents are read only by default; the Commands mode also allows commands rated low risk. Anything that needs approval is refused, host keys are never trusted by the server itself, and passwords come from the saved passwords.
- Every call is listed under Settings > MCP for 30 days, without its output; the server refuses to start when it cannot open that log. Settings > MCP also carries copy-ready entries for the supported clients.
- A GitHub button in the window bar opens the project page. The language button is gone; the language still lives in Settings.

## Improved

- Advanced host settings are grouped under Session and AI agents, name and color share a row, the agent switch explains itself in a help tooltip, and the proxy summary is a bordered box like the other inputs.
- iTerm2, kitty and sixel images decode in the background, so a large image no longer stalls a frame; the placement is reserved while decoding, and erases, resizes and kitty deletes still see it.
- Hovering a terminal link scans only the soft-wrapped group under the pointer instead of the whole scrollback, and saving one host re-encodes only that host’s record.

## Fixed

- The MCP group in Settings no longer collides with the cards around it, and its title and descriptions say what the user cares about.
