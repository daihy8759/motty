title: 快捷键
description: 默认快捷键，全部可以修改。
---
默认快捷键在 macOS 上使用 Command，在 Windows 和 Linux 上使用 Control。每个快捷键都可以在
设置里修改。

切换标签页到头后会循环，按住不放会连续切换。除字母和数字外，快捷键还可以绑定到 Tab、Page Up、Page Down、左方向键和右方向键。
在 macOS 上，Command+1 到 Command+9 还可以直接跳到第一到第九个标签页。

清空屏幕会同时清掉它上方的滚动历史，但光标所在的那一行会保留，正在输入的命令不会丢。

在远程桌面标签页里，Motty 的快捷键会暂停，按键都发给远端。**Ctrl+Alt+G** 释放键盘。
